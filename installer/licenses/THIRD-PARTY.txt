The Windows installer also carries these third party libraries, which the module downloader and the MySword / theWord
readers load at run time.  Each keeps its own licence.

OpenSSL 3 (libssl-3-x64.dll, libcrypto-3-x64.dll)
    Used for the HTTPS downloads.  Apache License 2.0: the text is in Apache-2.0.txt.
    https://www.openssl.org/

zlib (zlib1.dll), if it is present next to the program
    Needed by some builds of OpenSSL.  The zlib licence: https://zlib.net/zlib_license.html

SQLite (sqlite3.dll), if it is present next to the program
    Public domain.  https://www.sqlite.org/copyright.html
